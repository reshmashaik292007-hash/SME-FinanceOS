REDESIGN THE EXISTING SME FINANCEOS — CASHPULSE APPLICATION.

IMPORTANT:
The current application already has good functionality and working concepts.
DO NOT REMOVE OR BREAK the existing functionality.

This is a UI/UX REDESIGN and PRODUCT EXPERIENCE IMPROVEMENT.

The current UI feels too technical, too much like an AI developer console, and too dense.

Transform it into a simple, premium, highly understandable financial assistant designed specifically for small-business owners who may not be highly technical and may not be comfortable typing long messages.

The product should feel like:

"An AI CFO that anyone can talk to."

NOT:

"An AI developer dashboard."

============================================================
CORE UX PHILOSOPHY
============================================================

The owner should understand the dashboard within 5–10 seconds.

Use extremely simple language.

Instead of:

"Multi-Agent Protocol"

"Your AI Finance Team"

"Sequential AI agent coordination & handoffs"

"Your finance team checked everything for you."

Instead of:

"Risk detected: Liquidity Dip (Day 24)"

Do NOT expose unnecessary technical AI terminology.

Never show:
- latency
- API terminology
- protocol terminology
- technical agent orchestration terminology
- JSON-like information
- developer terminology

The owner doesn't care how the AI works.

The owner cares:

"How is my business doing?"

"What is wrong?"

"What should I do?"

VOICE INPUT
============================================================

Use the Web Speech API / browser speech recognition where supported.

Provide a graceful fallback if speech recognition is unavailable.

2. Show animated waveform.
